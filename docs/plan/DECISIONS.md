# سجل القرارات (ADR)

**الحالات:**

- `ACCEPTED`: مقبول ومعمول به.
- `PROPOSED`: مقترح بانتظار موافقتك.
- `PENDING`: مفتوح، يُحسم عند موعده.
- `SUPERSEDED`: استُبدل بقرار لاحق يُذكر رقمه.

القرار المقبول لا يُعدَّل، بل يُستبدل بقرار جديد.
